# BLUE MARKET v2 — 국제 키워드 강화판

## 포함 기능
- 최대 25명, 시작자금 1,000만원, 12턴(1~12월), 14개 가상 기업
- 실시간 매수·매도, 순위, 거래 내역, 온라인/오프라인 표시
- 플레이어 본인 자산 그래프 및 관리자 플레이어별 자산/보유주식 확인
- 관리자 암호 기본값 0403 (배포 시 `ADMIN_PIN` 환경변수로 변경 가능)
- 매월 주가 변동, 일부 계절성 가중치, 확률적 상장폐지
- 턴당 최대 13개 뉴스 선착순 배포, 관리자 개인 뉴스 전송, 사실/거짓 혼합
- 국제무역·환율·관세·FTA·글로벌 공급망·WTO·IMF·국제경영·현지화·법·디자인·마케팅·회계·항공물류 중심 퀴즈 100문항과 정답표
- 구걸/도박/랜덤카드 이벤트
- JSON 파일 자동 저장(단일 서버 인스턴스 기준)

## 실행
Node.js 18 이상에서 프로젝트 폴더 안에서 `npm install` 후 `npm start`. 브라우저에서 `http://localhost:3000`으로 접속합니다.

## Render 배포
GitHub 저장소에 업로드한 후 Render Web Service에서 Build Command=`npm install`, Start Command=`npm start`를 설정합니다. 환경변수 `ADMIN_PIN=0403`을 설정할 수 있습니다. `DATA_FILE`을 영구 디스크 경로로 지정하면 저장 파일 보존에 도움이 됩니다. 여러 인스턴스를 켜면 메모리 상태가 분리되므로 단일 인스턴스로 운영하세요.

## 주의
이것은 교육용 모의투자 게임이며 실제 투자 조언이 아닙니다. 실제 행사 전에 여러 브라우저/기기로 접속 테스트를 해주세요. 상장폐지 종목의 보유 주식은 평가액 0으로 계산됩니다. 구걸 이벤트는 주식 수량 단위로 손실을 계산하므로 보유 현금과 주식 구성에 따라 정확히 절반의 평가액과 차이가 날 수 있습니다. 실제 공개 배포 전에는 백업, 관리자 접근 제한, 접속 부하 테스트를 권장합니다.
